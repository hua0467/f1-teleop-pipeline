# 每日开机操作流程

> 每天早上来，按这个顺序走，5 分钟到位。

---

## 第一步：开机 + 激活环境

1. 电脑开机
2. 打开终端（Git Bash），粘贴下面两行：

```bash
cd C:/Users/Administrator/Documents/f1-teleop-pipeline
source /c/ProgramData/miniconda3/Scripts/activate f1-teleop
```

验证环境正常：
```bash
python scripts/01_test_environment.py
```
看到 `Environment check complete.` 就是 ok。

---

## 第二步：Quest 3 准备

1. Quest 3 开机（长按左侧电源键 3 秒，听到"噔"一声）
2. Quest 3 连 WiFi（设置 → Wi-Fi → 选公司 WiFi → 连接）
3. USB 数据线插电脑（必须是数据线，不是原装充电线）
4. 验证连接：

```bash
"C:/Users/Administrator/AppData/Local/Programs/SideQuest/resources/app.asar.unpacked/build/platform-tools/adb.exe" devices
```
看到 `2G0YC5ZH2Z006N  device` 就是连上了。

---

## 第三步：启动 Hand Tracking Streamer

1. 戴 Quest 3 → 按右手柄 O 形键（Meta 键）
2. 应用库（右下角 9 个圆点图标）
3. 右上角下拉 → 选「未知来源」
4. 找到 **Hand Tracking Streamer** → 打开
5. 检查配置：

| 设置 | 值 |
|------|-----|
| IP | `<PC 的局域网 IP>` |
| Port | `9000` |
| Protocol | UDP |
| Hands | Both |
| Show Landmarks | ✅ |
| Debug Info | ✅ |

6. 点 **Start** → 看到手上出现彩色追踪点 = 成功

---

## 第四步：PC 端开始录制

在终端（已激活 f1-teleop 环境）：

```bash
# 录制指定时长（例如 30 秒），自动保存 HDF5 + LeRobot 格式
python scripts/05_quick_record.py --duration 30 --fps 30 --output ./recordings
```

---

## 第五步：转 LeRobot 格式

```bash
python scripts/03_convert_to_lerobot.py --input ./recordings --output ./datasets/你的数据集名称
```

## 快捷命令速查

```bash
# 看 Quest 3 连上没有
"$SIDEQUEST_ADB" devices

# 手动启动 Hand Tracking Streamer（不用戴头显找）
"$SIDEQUEST_ADB" shell monkey -p com.wengmister.handtrackingstreamer -c android.intent.category.LAUNCHER 1

# 激活环境
source /c/ProgramData/miniconda3/Scripts/activate f1-teleop

# 验证环境
python scripts/01_test_environment.py

# 录制（指定时长，自动保存 HDF5 + LeRobot）
python scripts/05_quick_record.py --duration 30 --fps 30
```

## 常见问题速查

| 问题 | 解决 |
|------|------|
| ADB 检测不到 Quest 3 | 检查数据线是不是充电线、重插 USB、重启 ADB (`adb kill-server`) |
| UDP 收不到数据 | Quest 3 没连 WiFi、IP 填错了、PC 防火墙拦截 |
| 脚本报 UnicodeEncodeError | 路径里有中文/emoji，用纯英文路径 |
| Hand Tracking Streamer 找不到 | 去「未知来源」里找，不在主应用列表 |
| SideQuest 打不开 | 开 Clash 代理 |
